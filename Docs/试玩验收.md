# Unity 内试玩验收清单

以下项目**尚未执行**，需在本机 Unity 中逐项验证。建议用默认 16:9 Game 窗口开始。

## 工程与资源

- [ ] Unity 2022.3 LTS 导入，无 Console 编译错误。
- [ ] 打开入口场景点击 Play，可看到地图、角色与 HUD。
- [ ] 执行 Generate Editable Whitebox 后，非 Play 状态也可看到完整地形。
- [ ] 保存、关闭并重开生成场景，坡道碰撞与材质仍存在。
- [ ] 执行 Validate Current Scene Floors，9 个引擎内地面检查通过。

## 地图与移动

- [ ] WASD、鼠标右键、方向键、冲刺、蹲伏正确；低顶下不穿顶站起。
- [ ] 沿礼拜堂走通，北端 E 开门，无卡碰撞。
- [ ] 沿钟楼走通，上坡、+8m 平台、下坡无断层。
- [ ] 中央庭院可走左右侧路；也可从南坡下到花园，再沿北坡上来。
- [ ] 回廊连接圣剑殿，没有不可越过的缝隙。
- [ ] 相机在墙角、顶棚和高差处不持续穿墙或剧烈抖动。
- [ ] 跌落、手动 R、龙息失败都能回到正确检查点。

## 潜入规则

- [ ] 开阔处在龙头有效视野内，发现值会上升。
- [ ] 实体顶棚/墙壁确实能中断视线；普通地面颜色不影响结果。
- [ ] 屋顶破口与方向性遮挡可解释，不出现隔墙全知追踪。
- [ ] 站立发现比蹲伏快；移开后发现值下降。
- [ ] 龙息锁定后有可见预警；移出圆盘可活下来。
- [ ] 橙色区域内有有效实体遮挡时不应穿墙命中。
- [ ] 搜索会结束，并能恢复巡游。
- [ ] 钟可在巡游时诱导，警觉时给出拒绝提示，冷却期间不能重复触发。

## 完整闭环

- [ ] 壁画可交互，提示显示足够久。
- [ ] 栅门在失败后保持开启。
- [ ] 到达圣剑附近，E 触发巨龙靠近，不再被持续追杀。
- [ ] 登龙后角色位于背上，镜头可看见此前走过的地图。
- [ ] 飞行结束出现完成信息，Q/E 观察不改变预设航线。
- [ ] 构建到本机后，独立程序仍能完整通关。

## 已执行的非引擎检查

`python3 tools/validate_whitebox.py` 对 Unity 使用的同一份地图 JSON 检查了：

- 83 个体块的合法尺寸、4 段坡道的倾角。
- 西路线 1061 个、东路线 1068 个、花园路线 324 个采样点的地面连续性与站立空间。
- 出生点、检查点、终点有地面，检查点上方存在顶棚。

检查假设交互门已经打开，忽略运行中的巨龙与角色控制器实际求解，不模拟镜头、感知、输入、物理接触或胜利演出。上述结果不能替代本清单。
